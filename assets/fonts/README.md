# Manrope

Source: https://github.com/google/fonts/tree/main/ofl/manrope
License: SIL Open Font License, included in OFL.txt.

Manrope-Regular.ttf is a static weight-400 instance of Manrope[wght].ttf,
created with fontTools.varLib.instancer. Manrope-Tabular.ttf uses the same
instance with Unicode digit mappings replaced by the font's `tnum` GSUB
glyphs, because egui does not apply this OpenType feature. Its countdown
digits have equal advances. The normal UI retains proportional digits.

Both fonts are embedded in the executable for offline use. egui's bundled
fonts remain available as fallback for characters Manrope does not cover.
